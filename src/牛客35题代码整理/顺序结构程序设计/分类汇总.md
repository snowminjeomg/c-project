## 乘法表

- 题目 ID：22206
- 状态：已通过
- 来源：依据题面补写
- 独立源码：`乘法表.c`

```c
#include <stdio.h>

int main(void)
{
    int row, column;

    for (row = 1; row <= 9; row++) {
        for (column = 1; column <= row; column++) {
            printf("%d*%d=%2d", column, row, column * row);
            if (column < row) {
                putchar(' ');
            }
        }
        putchar('\n');
    }

    return 0;
}
```
